# Contributing

1. Create a branch from `main`.
2. Keep templates self-contained and document any new asset license.
3. Do not commit copyrighted music, user uploads, generated outputs, or third-party brand assets.
4. Run `pytest` before opening a pull request.
5. Test a short render when changing audio analysis or frame drawing.

Template contributions should include a renderer, a lightweight preview, and an entry in `templates.json`.
